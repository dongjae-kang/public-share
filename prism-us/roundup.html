정직 표시 (프로토타입 주석)
① 데이터 = KR 파일럿 실데이터. 카드 291장(5/18~7/10) + 일일 후보 클러스터 집계(40/54일 보존). 지어낸 카드·수치 0.
② 이슈 경계·중립 제목 = 큐레이터 역할 시뮬레이션. 운영 = 자동 후보생성 + 큐레이터 confirm.
③ 옅은 음영(관련 영상량) = max(그날 매칭 클러스터 집계, 그날 발행 카드의 클러스터 영상 수 실측). 카드는 그날 영상 묶음에서 만들어지므로 카드 있는 날 = 반드시 유입 있는 날. 원본 영상은 보존하지 않고 집계만 남긴다(YouTube API 30일 정책 정합). 한계: Top10 밖·누락 14일 유입은 과소표시 가능.
④ ▲ 무게 상승 = escalation 실계 8회(6/11 이틀분 2건 포함, 표시 날짜 7일). 투표용지 사태만 태깅 존재.
⑤ '최근 전개' = 투표용지 사태는 실제 큐레이션 new_fact, 나머지는 최신 카드 제목 대용.
⑥ 표시 상태 = 진행 중 / 지난 이슈 2단계. 내부 상태기계는 7일(휴면)·21일(종결) 유지 — 재활성·운영 판단용, 유저 비노출. 승격 = 같은 이슈 카드 5일치 이상(Jack 7/11 상향) — 그 미만(예: 한화에어로 폭발 3일·젠슨 황 방한 3일·삼성 노사 4일)은 내부 '추적 중'으로만 유지, 5일 도달 시 그간 카드가 소급 노출. 2카드 추적 예: 국민의힘 윤리위 장동혁 징계 심사 / 개정 정보통신망법 시행 논란 / 리센느 원이 '무섭노' 발언 논란.
⑦ 이슈 클릭 = 상세(continuity). 투표용지 사태만 v10 데모 연결, 나머지 미구현. 헤더 네비 = 사이트 목업(비활성).
